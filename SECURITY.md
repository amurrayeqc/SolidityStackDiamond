# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting or a private Security Advisory for this repository when available. Include affected versions, reproduction steps, impact, and any suggested mitigation. If private reporting is unavailable, contact the maintainer through the links on the GitHub profile without including secrets in the initial message.

Reports will be reviewed as time permits. This project is provided without a promise of professional security auditing or a guaranteed response time.
