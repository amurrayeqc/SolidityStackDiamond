# Contributing

Thanks for improving this project.

## Development

1. Fork the repository and create a focused branch.
2. Install the dependencies using the commands in the README.
3. Add or update tests for behavior changes.
4. Run the complete test suite before opening a pull request.
5. Keep commits small and explain the user-visible impact in the pull request.

Please avoid unrelated formatting changes and never commit credentials, private keys, generated secrets, or local environment files.
